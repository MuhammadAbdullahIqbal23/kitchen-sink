# Security policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub's private vulnerability reporting](https://github.com/MuhammadAbdullahIqbal23/kitchen-sink/security/advisories/new), with steps to reproduce and the version affected. You'll get a reply within a week.

## Scope

The skill's scripts (`skills/kitchen-sink/scripts/`) run on users' machines, so issues there, such as reading or writing outside the project folder or running unexpected commands, are in scope. So are the CI workflows in `.github/`.
